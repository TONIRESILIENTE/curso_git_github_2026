kgit init . 		 -> Cria um repo git na pasta atual
git status 		 -> Mostra o status  do trabalho 
git add			 -> Adiciona arquivo para ser editado
git commit -m "msg" 	 -> Faz commit do que estava para ser comitado

## FLUXO DE TRABALHO
1. criar diretório do projeto
2. iniciar do git dentro do diretório criado(git init .)
3. edita ou cria arquivos
4. git status
5. git add <nome do arquivo>
6. git commit -m "mensagem"
7. volta para o passo 3
